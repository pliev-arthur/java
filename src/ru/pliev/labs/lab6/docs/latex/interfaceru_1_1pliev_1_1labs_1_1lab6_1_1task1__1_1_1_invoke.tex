\doxysubsection{Detailed Description}
Аннотация для автоматического вызова методов через Reflection API. 

Аннотация {\ttfamily @\+Invoke} предназначена для пометки методов, которые должны быть автоматически вызваны обработчиком {\ttfamily \doxylink{}{Invoke\+Annotated\+Methods}} во время выполнения программы. 

{\bfseries{Характеристики аннотации\+:}}


\begin{DoxyItemize}
\item Цель применения\+: только МЕТОД 
\item Доступна во время исполнения программы 
\item Не имеет свойств 
\end{DoxyItemize}

{\bfseries{Пример использования\+:}}


\begin{DoxyPre}
{\ttfamily \newlinepublic class ExampleClass \{\newline    @Invoke\newline    public void annotatedMethod() \{\newline        System.out.println("{}Этот метод будет вызван автоматически"{});\newline    \}\newline\}\newline}
\end{DoxyPre}
